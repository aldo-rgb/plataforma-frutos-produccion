Currency Feature (Agregado hoy)
--------------------------------------------------------------------------------
Problema resuelto:
- Se necesitaba soporte para USD y MXN en precios
- Los precios se mostraban siempre como "MXN" hardcodeado

Solución implementada:

1. Schema: Agregado currency a DefaultPrice y SchoolProduct
2. Migration: Usado script SQL raw para agregar columna:
   ALTER TYPE "Currency" ADD VALUE IF NOT EXISTS 'USD';
   ALTER TABLE "DefaultPrice" ADD COLUMN currency "Currency" NOT NULL DEFAULT 'MXN';
   ALTER TABLE "SchoolProduct" ADD COLUMN currency "Currency" NOT NULL DEFAULT 'MXN';

3. UI en /precios: Switch de moneda que actualiza todos los 5 niveles
4. Vision Builder: Detecta currency de DefaultPrice y:
   - Muestra labels dinámicos: "💰 Costo del Nivel Básico (USD)" o "(MXN)"
   - Formato de display: "USD 500" o "$500"
   - Pasa currency al API al crear visión
5. Productos creados: Heredan el currency configurado

Formato de Display:
{productPrices.currency === 'USD' ? 'USD ' : '$'}{amount.toLocaleString()}
// Resultado: "USD 1,500" o "$1,500"

BUGS CONOCIDOS Y SOLUCIONES
================================================================================

1. Prisma db push no funciona confiable
--------------------------------------------------------------------------------
Problema: npx prisma db push a veces no aplica cambios al schema

Solución aplicada: Scripts SQL raw con Node.js

const { PrismaClient } = require('@prisma/client');
const prisma = new PrismaClient();

await prisma.$executeRawUnsafe(`
  ALTER TABLE "DefaultPrice" 
  ADD COLUMN IF NOT EXISTS currency "Currency" NOT NULL DEFAULT 'MXN';
`);

2. NaN en precios
--------------------------------------------------------------------------------
Problema: Valores NaN se guardaban en base de datos

Solución: Validación estricta en handlePriceChange

const numValue = typeof value === 'number' ? value : parseFloat(value);
processedValue = isNaN(numValue) ? (field === 'basePrice' ? 0 : null) : numValue;

3. P2022 Error en upsert
--------------------------------------------------------------------------------
Problema: upsert fallaba con "Record not found"

Solución: Cambiar a findFirst + conditional update/create

const existing = await prisma.defaultPrice.findFirst({ where });
if (existing) {
  await prisma.defaultPrice.update({ where: { id: existing.id }, data });
} else {
  await prisma.defaultPrice.create({ data });
}

4. Currency mostraba duplicado
--------------------------------------------------------------------------------
Problema: Display mostraba "USD $500 USD"

Solución: Cambiar formato de display

// ANTES: {currency === 'USD' ? 'USD $' : '$'}{amount} {currency}
// AHORA: {currency === 'USD' ? 'USD ' : '$'}{amount}
