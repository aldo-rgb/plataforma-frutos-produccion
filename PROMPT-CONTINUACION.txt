## 🏗️ ARQUITECTURA GENERAL

### Stack Tecnológico
- **Framework**: Next.js 16.1.1 (App Router) con Turbopack
- **Base de datos**: PostgreSQL con Prisma 5.22.0
- **Auth**: NextAuth.js
- **UI**: TailwindCSS + Framer Motion
- **Storage**: Supabase (imágenes/archivos)
- **Hosting**: El repositorio está en GitHub: `aldo-rgb/plataforma-frutos-produccion`

### Estructura de Carpetas Principal
```
/app
  /api                    # API Routes
  /auth                   # Páginas de autenticación
  /checkout               # Flujo de compra/registro
  /dashboard              # Dashboards por rol
    /coordinador          # Dashboard coordinador avanzado
    /coordinador-basico   # Dashboard coordinador básico y trainers
    /school-admin         # Dashboard admin de escuela
    /participante         # Dashboard participante (alumno)
/components               # Componentes React
/lib                      # Utilidades, prisma client, auth config
/prisma                   # Schema de base de datos
```

## ✅ FUNCIONALIDADES COMPLETADAS

### 1. Sistema de Tesorería (Treasury)
- **Códigos de Pago**: Generación con palabras quantum (QUARK, NEBULA, PHOTON, etc.)
- **Gastos**: Registro, aprobación, rechazo con comprobantes
- **Cortes de Caja (CashBatch)**: 
  - Coordinador crea corte con códigos + gastos
  - Director genera código de confirmación quantum
  - Director de tesorería confirma con el código
- **Dashboard Treasury** para coordinadores y school-admin
- **Widgets**: Códigos generados, canjeados, gastos pendientes

### 2. Sistema de Registro/Signup
- Flujo: Selección de sede → Formulario → Checkout → Pago
- **Validación**: Si no hay visión activa, NO permite registro
- **Referidos**: Sistema de códigos de invitación
- **Códigos de pago**: Se canjean en checkout

### 3. Sistema de Visiones
- Inscripciones (vision_enrollments)
- Niveles: BASIC → ADVANCED → PL
- Búsqueda de visión activa corregida (no solo futuras, también en curso)

### 4. Formularios Médicos
- Widget de alertas médicas para coordinadores
- Listado de formularios con alertas
- Acknowledgment de coordinadores

### 5. Squads (Pequeños Grupos)
- Creación y gestión de grupos
- Asignación de Game Changers como líderes
- Miembros de grupo

### 6. Dashboards por Rol
- `/dashboard/participante` - Vista de participante
- `/dashboard/coordinador` - Coordinador avanzado
- `/dashboard/coordinador-basico` - Coordinador básico, trainer, coordinator_advanced
- `/dashboard/school-admin` - Admin de escuela
