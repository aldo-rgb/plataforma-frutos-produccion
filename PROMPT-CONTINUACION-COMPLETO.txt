## CONTEXTO GENERAL

Estás trabajando en **Plataforma Frutos**, una aplicación Next.js 14 con App Router para gestión de entrenamientos de transformación personal. La plataforma maneja inscripciones, tickets, llamadas de seguimiento, y múltiples roles de usuario.

---

## STACK TECNOLÓGICO

- **Framework**: Next.js 14 (App Router)
- **Base de datos**: PostgreSQL con Prisma ORM
- **Autenticación**: NextAuth.js
- **UI**: TailwindCSS, Framer Motion, Lucide Icons
- **Deployment**: Vercel (rama main)
- **Repositorio**: `aldo-rgb/plataforma-frutos-produccion`
- **Directorio local**: `/Users/aldokmps/plataforma-frutos-FINAL`

```
PARTICIPANTE - Usuario inscrito en entrenamientos
```

```prisma
model vision_enrollments {
  id               Int

  enrollmentStatus String       // ENROLLED, ACTIVE, PENDING, DROPPED
```

### Ticket
```prisma
model Ticket {
  id             String @id @default(uuid())
  ownerId        Int
  visionId       Int
  level          VisionLevel  // BASIC, ADVANCED, PL
  status         TicketStatus // ACTIVE, PENDING_PAYMENT, TRANSFERRED, EXPIRED, CANCELLED
  paymentStatus  TicketPaymentStatus // PAID, PARTIAL, PENDING, UNPAID, GIFT
  costAtPurchase Decimal
  amountPaid     Decimal
  type           TicketType   // STANDARD, PROMO, GIFT
  
  // Relaciones (minúsculas)
  owner          Usuario @relation("TicketOwner")
  vision         Vision
  organization   Organization
}
```

## LÓGICAS IMPORTANTES

### Deadline de Pago PL
```typescript
// El deadline es 12:00 PM del día de advancedStartDate
function isPaymentDeadlinePassed(advancedStartDate: string | null): boolean {
  if (!advancedStartDate) return false;
  const deadline = new Date(advancedStartDate);
  deadline.setHours(12, 0, 0, 0);
  return new Date() >= deadline;
}
```

### Filtrar Llamadas ADVANCED (usuarios pagados)
```typescript
// 1. Obtener usuarios con tickets ADVANCED pagados
const paidTickets = await prisma.ticket.findMany({
  where: {
    level: 'ADVANCED',
    status: 'ACTIVE',
    paymentStatus: 'PAID',
    visionId: { in: visionIds }
  },
  select: { ownerId: true }
});

// 2. Filtrar enrollments de esos usuarios
const enrollments = await prisma.vision_enrollments.findMany({
  where: {
    level: 'ADVANCED',
    enrollmentStatus: { in: ['ENROLLED', 'ACTIVE'] },
    userId: { in: paidTickets.map(t => t.ownerId) }
  }
});
```

### Conteo de Inscripciones
```typescript
// Contar vision_enrollments, NO VisionParticipante
const count = await prisma.vision_enrollments.count({
  where: {
    visionId,
    level: 'BASIC', // o 'ADVANCED'
    enrollmentStatus: { in: ['ENROLLED', 'ACTIVE'] }
  }
});
```

## CONVENCIONES DE CÓDIGO - MUY IMPORTANTE

### Prisma - Nombres de campos (CRÍTICO)
```typescript
// ✅ CORRECTO - usar minúsculas para relaciones
ticket.vision
ticket.organization
enrollment.Usuario_vision_enrollments_userIdToUsuario

// ❌ INCORRECTO - NO usar mayúsculas
ticket.Vision  // Error: Property 'Vision' does not exist
ticket.Organization  // Error: Property 'Organization' does not exist
```

### API Routes con params dinámicos (Next.js 14)
```typescript
// Los params son Promise en Next.js 14
export async function GET(
  request: Request,
  { params }: { params: Promise<{ id: string }> }
) {
  const resolvedParams = await params;
  const id = resolvedParams.id;
  // ...
}
```

## ERRORES COMUNES Y SOLUCIONES

### Error: Property 'Vision' does not exist on type
**Causa**: Usando mayúscula en relación de Prisma
**Solución**: Usar `vision` en minúscula

### Error: Property 'vision_enrollment' does not exist
**Causa**: Usando singular en lugar de plural
**Solución**: Usar `vision_enrollments` (plural)

### Error: params.id is a Promise
**Causa**: Next.js 14 cambió params a Promise
**Solución**: `const { id } = await params;`
