Soy el desarrollador de "Plataforma Frutos", una aplicación Next.js 14 con App Router 
para gestión de programas de desarrollo personal llamados "Vision". La plataforma 
maneja entrenamientos en 3 niveles: BASIC, ADVANCED y PL (Program Leadership).

STACK TECNOLÓGICO:
- Next.js 14 (App Router)
- TypeScript
- Prisma ORM con PostgreSQL
- NextAuth.js para autenticación
- Tailwind CSS
- Desplegado en Vercel

model Usuario {
  id                    Int       @id @default(autoincrement())
  nombre                String
  email                 String    @unique
  password              String
  telefono              String?
  imagen                String?
  rol                   Rol       @default(PARTICIPANTE)
  // Roles: ADMINISTRADOR, COORDINADOR, TRAINER, MENTOR, GAMECHANGER, PARTICIPANTE
  tier                  String?   // "frutos_free", "frutos_pro", etc.
  suscripcion           String?
  organizationId        Int?
  currentVisionLevel    String?   // "BASIC", "ADVANCED", "PL"
  graduatedFromBasic    Boolean?
  graduatedFromAdvanced Boolean?
  assignedMentorId      Int?      // Mentor asignado para llamadas
  mentorId              Int?      // Si este usuario ES mentor
}

FUNCIONALIDADES IMPLEMENTADAS

--------------------------------------------------------------------------------
1. AUTENTICACIÓN Y ROLES
--------------------------------------------------------------------------------
- Login/Logout con NextAuth
- Roles: ADMINISTRADOR, COORDINADOR, TRAINER, MENTOR, GAMECHANGER, PARTICIPANTE
- Middleware de protección de rutas por rol

--------------------------------------------------------------------------------
2. DASHBOARD PRINCIPAL (/dashboard)
--------------------------------------------------------------------------------
- Widget de carta de frutos con progreso
- Widget de tareas pendientes
- Widget de llamadas con mentor
- Widget de El Atravesar (para coordinadores/trainers)
- Acceso condicional según nivel (BASIC, ADVANCED, PL)

--------------------------------------------------------------------------------
3. WIZARD DE CARTA v2 (/dashboard/carta/wizard-v2)
--------------------------------------------------------------------------------

FLUJO EN 5 PASOS:
1. SER: Declaraciones de poder ("Yo soy...") por área
2. Objetivo: Meta principal de cada área
3. HACER: Acciones específicas con frecuencia
4. Acciones: Configuración de días y repeticiones
5. Revisión: Resumen final antes de guardar

LÓGICA DE ÁREAS:
- Usuarios Vision: 8 áreas (6 básicas + 2 de servicio)
- Usuarios orgánicos (Lobo Solitario): 6 áreas básicas
- Botón de configurar áreas (6) DESHABILITADO para usuarios Vision

--------------------------------------------------------------------------------
4. SISTEMA DE ACCESO POR NIVEL (VisionAccessContext)
--------------------------------------------------------------------------------

API: /api/user/vision-level
Determina acceso según nivel:
- BASIC: ranking, quantum, llamadasMentor
- ADVANCED: + carta, metas
- PL: + tareas, evidencias, disciplina (acceso completo)

IMPORTANTE: Busca enrollments con status 'ENROLLED' o 'ACTIVE'

--------------------------------------------------------------------------------
5. EL ATRAVESAR (/el-cruce)
--------------------------------------------------------------------------------

Sistema de "cruces" para pasar de nivel:
- BASIC → ADVANCED
- ADVANCED → PL

FLUJO:
1. Coordinador/Trainer selecciona producto IN_PROGRESS
2. Crea sesión de cruce
3. Participante responde preguntas
4. Páginas del flujo: /el-cruce/[sessionId]/tu-vida, etc.

APIS:
- POST /api/el-cruce/session - Crear sesión
- GET /api/el-cruce/session?active=true - Sesiones activas
- GET /api/coordinador/productos-activos - Productos disponibles

--------------------------------------------------------------------------------
6. SISTEMA DE SQUADS Y GAMECHANGERS
--------------------------------------------------------------------------------
- Creación de squads por nivel
- Asignación de GameChangers
- Registro de llamadas (GCCallAttempt)
- Monitor de llamadas (/api/coordinator/gc-calls-monitor)

--------------------------------------------------------------------------------
7. CHECK-IN DE ENTRENAMIENTOS
--------------------------------------------------------------------------------
- QR por producto/día
- Registro en CheckInRecord
- Página: /dashboard/school-admin/checkin/[productId]

--------------------------------------------------------------------------------
8. MENTORES
--------------------------------------------------------------------------------
- Horarios disponibles (MentorAvailability)
- Agendar llamadas (MentorCall)
- Asignación automática de mentores
