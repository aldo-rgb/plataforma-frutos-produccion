🐛 PROBLEMAS CONOCIDOS Y SOLUCIONES
================================================================================

1. Replicate API en build
   Problema: Error al inicializar Replicate en build time
   Solución: Lazy initialization con getReplicate() function
   Archivos afectados:
   - /app/api/avatar/generate-from-selfie/route.ts
   - /app/api/mentor/generate-avatar-from-selfie/route.ts

2. i18n messages path
   Problema: 404 en producción por path incorrecto
   Solución: Usar @/messages/${locale}.json en /i18n.ts

3. Prisma en Vercel
   Problema: Cliente no generado
   Solución: "postinstall": "prisma generate" en package.json

4. Build con errores de tipos
   Solución: Ejecutar npx prisma generate antes de build

5. Socket.io con múltiples instancias
   Solución: Redis adapter configurado (@socket.io/redis-adapter)
