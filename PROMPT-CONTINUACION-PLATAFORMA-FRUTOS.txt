## ✅ FUNCIONALIDADES COMPLETADAS

### 1. Sistema de Check-in (`/staff/check-in/[productId]`)
- Scanner omnidireccional (QR cámara, pistola barcode, NFC)
- Validación de: ticket, formulario médico, foto de perfil
- **Validación de prerrequisitos**: ADVANCED requiere haber asistido a BASIC
- **Validación de bitácora**: ADVANCED requiere AdvancedQuestionnaire.status === 'COMPLETED'
- Captura de foto en tiempo real si no tiene
- Generación e impresión de gafetes
- **Escritura NFC** en tarjetas NTAG 213/215/216 (NO funciona con MIFARE Classic)
- Consumo automático de licencias de organización
- Registro de CheckInRecord
- Actualización de attendanceStatus en vision_enrollments

### 2. Bitácora de Inicio (`/bitacora`)
- Cuestionario de 5 dimensiones para usuarios ADVANCED
- Auto-guardado cada cambio de sección
- Indicadores visuales de progreso
- Scroll automático al cambiar de sección
- Widget de alerta en dashboard para usuarios que no han completado

### 3. Sistema de Tickets
- Códigos CASH canjeables en `/dashboard/checkout-ticket`
- Validación: `data.success && data.giftCode` (NO `data.valid`)
- Tipos de pago: CASH, CARD, TRANSFER

### 4. Dashboard
- `BitacoraAlertWidget` muestra alerta si usuario tiene enrollment ADVANCED sin bitácora completada
- Filtra por paymentStatus: `['PAID', 'FULL', 'PARTIAL', 'GIFT']`

### 5. Panel de Gestión (`/manage`)
- Lista de enrollments con attendanceStatus
- Filtros por nivel, estado, organización

## ⚠️ BUGS CONOCIDOS Y SOLUCIONES APLICADAS

### Bug: Check-in ADVANCED actualizaba enrollment BASIC
**Causa**: `validate/route.ts` no filtraba por `level` al buscar enrollment
**Solución**: Agregar mapeo levelType → level y buscar enrollment específico:
```typescript
const levelMap = { 'BASIC': 'BASIC', 'ADVANCED': 'ADVANCED', 'PL': 'PL', ... };
const enrollmentLevel = levelMap[product.levelType];
enrollment = await prisma.vision_enrollments.findFirst({
  where: { userId, visionId, level: enrollmentLevel }
});
```

### Bug: NFC no grababa al primer click
**Causa**: Android requiere `scan()` antes de `write()`
**Solución**: En `BadgePreview.tsx`, hacer scan primero y escribir en `onreading`:
```typescript
await ndef.scan({ signal: abortController.signal });
ndef.onreading = async () => {
  await ndef.write({ records: [...] }, { overwrite: true });
};
```

### Bug: MIFARE Classic no funciona con Web NFC
**Causa**: Web NFC API solo soporta NDEF (NFC Forum tags)
**Solución**: Usar tarjetas NTAG 213/215/216, NO MIFARE Classic/IsoDep

### Bug: Bitácora no guardaba (error campos inválidos)
**Causa**: El objeto `data` contenía campos como `id`, `Vision`, `createdAt` que Prisma rechazaba
**Solución**: Filtrar campos válidos antes de guardar:
```typescript
const validFields = ['familyDescription', 'familyDynamics', ...];
const filteredData = Object.fromEntries(
  Object.entries(data).filter(([key]) => validFields.includes(key))
);
```

## 🎯 FLUJO DE CHECK-IN AVANZADO

```
1. Staff escanea QR/busca participante
2. validate/route.ts verifica:
   - ✓ Tiene ticket válido (ENROLLED)
   - ✓ Formulario médico completado
   - ✓ Asistió a BÁSICO (attendanceStatus === 'ATTENDED')
   - ✓ Bitácora completada (AdvancedQuestionnaire.status === 'COMPLETED')
   - ○ Tiene foto (no bloqueante)
3. Si todo OK → badge_print → grabar NFC/imprimir
4. Verificar gafete (scan QR del gafete)
5. complete/route.ts:
   - Crea CheckInRecord
   - Actualiza attendanceStatus → 'ATTENDED'
   - Consume licencia de organización
   - Crea LicenseAssignment si aplica
```
