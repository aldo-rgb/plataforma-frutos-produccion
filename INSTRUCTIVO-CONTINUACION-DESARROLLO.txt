case 'close_poll': {
  // ... determinar ganador ...
  
  if (winnerProject.estimatedBudget && Number(winnerProject.estimatedBudget) > 0) {
    // Obtener miembros de ambas fuentes
    const visionEnrollments = await prisma.vision_enrollments.findMany({...});
    const visionParticipantes = await prisma.visionParticipante.findMany({...});
    
    // Combinar IDs sin duplicados
    const memberIdSet = new Set<number>();
    visionEnrollments.forEach(ve => memberIdSet.add(ve.userId));
    visionParticipantes.forEach(vp => memberIdSet.add(vp.participanteId));
    
    const memberIds = Array.from(memberIdSet);
    const perPersonAmount = Math.ceil((totalBudget / memberIds.length) * 100) / 100;

    // Crear presupuesto
    const newBudget = await prisma.tribeBudget.create({
      data: {
        visionId: parseInt(visionId),
        name: `🌱 ${winnerProject.name}`,
        description: `Presupuesto comunitario para: ${winnerProject.description}`,
        totalAmount: totalBudget,
        isActive: true,
        createdById: userId
      }
    });

    // Crear pagos para cada miembro
    await prisma.tribeBudgetPayment.createMany({
      data: memberIds.map(memberId => ({
        budgetId: newBudget.id,
        userId: memberId,
        amount: perPersonAmount,
        isPaid: false
      }))
    });
  }
}

🔴 GUÍA CRÍTICA: NOMBRES DE RELACIONES PRISMA
================================================================================

CONTEXTO DEL PROBLEMA:
----------------------
Prisma genera nombres de relaciones VERBOSE cuando un modelo tiene múltiples 
foreign keys que apuntan a la misma tabla. Este es el error más común en el 
proyecto y causa errores 500 tipo:

  "Unknown field 'user' for include statement on model 'SmallGroupMember'"
  "Unknown field 'members' for include statement on model 'SmallGroup'"

REGLA DE ORO:
-------------
NUNCA asumir nombres de relaciones. SIEMPRE verificar en prisma/schema.prisma
buscando el modelo y sus relaciones con @relation()

CÓMO VERIFICAR NOMBRES DE RELACIONES:
-------------------------------------

1. Buscar el modelo en schema.prisma:
   grep -A30 "model SmallGroupMember {" prisma/schema.prisma

2. Buscar las líneas con @relation():
   - El nombre ANTES del tipo es el nombre a usar
   - Ejemplo: "Usuario_SmallGroupMember_userIdToUsuario Usuario @relation(...)"
   - Nombre a usar: Usuario_SmallGroupMember_userIdToUsuario

3. Verificar desde el otro lado de la relación:
   grep "SmallGroupMember" prisma/schema.prisma | grep -v "model"

ERRORES COMUNES Y SOLUCIONES:
-----------------------------

Error: "Unknown field 'X' for include statement on model 'Y'"
Solución: Buscar en schema.prisma el nombre correcto de la relación

Error: "Cannot read properties of undefined (reading 'map')"
Causa: Usaste el nombre incorrecto y Prisma no incluyó los datos
Solución: Corregir el nombre de la relación en include Y en el código que accede
